# Flow Pilot agent instructions

- Read `PROJECT_CONTEXT.md`, `STATUS.md`, and `HANDOFF.md`, then inspect Git status and relevant code. Reconcile discrepancies against the repository.
- Preserve other contributors’ work. Keep changes scoped and avoid concurrent edits to the same files.
- Keep the product, endorsements, dashboard data, and pricing clearly fictional. Accounts, billing, integrations, and AI are outside the demo scope.
- Run the production build and verify affected flows. Record results in `STATUS.md` and leave a compact handoff with files, checks, and next steps.
- Ask before destructive changes, external account changes, publishing, pushing, or introducing paid services.
